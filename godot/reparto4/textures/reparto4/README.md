# Texture PBR di "Reparto 4" — fonti e licenze

Tutte le texture in questa cartella sono fotografie PBR (diffuse + normal + roughness + ambient
occlusion) scaricate da [Poly Haven](https://polyhaven.com), libreria di asset a licenza
**CC0 1.0** (pubblico dominio): uso libero, anche commerciale, nessun obbligo di attribuzione.

| Cartella | Asset Poly Haven | Uso nella scena |
|---|---|---|
| `anti_skid_tiles/` | [anti_skid_tiles](https://polyhaven.com/a/anti_skid_tiles) | Pavimento del corridoio |
| `blue_plaster_weathered/` | [blue_plaster_weathered](https://polyhaven.com/a/blue_plaster_weathered) | Pareti (intonaco scrostato) |
| `brushed_concrete/` | [brushed_concrete](https://polyhaven.com/a/brushed_concrete) | Pavimento delle stanze laterali |
| `blue_metal_plate/` | [blue_metal_plate](https://polyhaven.com/a/blue_metal_plate) | Barelle, armadietti, letti |
| `rusty_metal_02/` | [rusty_metal_02](https://polyhaven.com/a/rusty_metal_02) | Porta d'uscita |

Ogni cartella contiene `diff.jpg` (colore), `nor_gl.jpg` (normal map, convenzione OpenGL — quella
che usa Three.js), `rough.jpg` (rugosità) e `ao.jpg` (occlusione ambientale), risoluzione 1k.
